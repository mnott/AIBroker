Build a small Python CLI wordfreq.py in this directory that prints the 5 most frequent words of a text file, with a unittest in test_wordfreq.py. Delegate the implementation to a PAI worker: write the spec to a file, run `pai worker run --class implement -p "$(cat spec.txt)" --output-format json` in the background, and show it live with `pai worker pane <id>` (get the id from `pai worker ps`). When the worker finishes, review its result, run the tests yourself and report in three lines what the worker did and whether the tests pass.
